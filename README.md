# Ci-Jian Yang — Academic Website

Academic website for **Ci-Jian Yang / Surface Processes & Landforms**, Department of Geography, National Taiwan University.

## Structure

- `index.html` — page content and semantic structure
- `css/style.css` — responsive layout and visual design
- `js/main.js` — language switcher and mobile navigation
- `.nojekyll` — publish static files directly with GitHub Pages

## Local preview

Open `index.html` directly, or run a simple local HTTP server.

## Deployment

This repository is intended for GitHub Pages at:

`https://ntugeomo.github.io/cijianyang/`

GitHub is the canonical source of the website. Future edits can be made through Codex and committed to this repository.
